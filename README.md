# Linesmith

Linesmith is a desktop app for Windows and Linux that turns your videos into subtitles, translates them into 33 languages and can dub them with an AI voice. Your video files stay on your computer.

**Website, pricing and help:** https://algowisp.com/linesmith/

## Download

Get the latest version from [Releases](https://github.com/Algo1493/linesmith/releases/latest):

- **Windows 10/11 (64-bit):** `Linesmith-Setup.exe`
- **Linux (x86-64):** `Linesmith-x86_64.AppImage` — make it executable (`chmod +x Linesmith-x86_64.AppImage`) and run it.

The first 3 videos are free with every feature. After that, Linesmith asks for a license key, which you can buy on the [website](https://algowisp.com/linesmith/#pricing).

This repository only hosts the installers; Linesmith is commercial software and its source code is not published here.
